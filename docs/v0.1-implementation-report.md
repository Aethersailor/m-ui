# m-ui v0.1 实现报告

日期：2026-07-28

## 1. 实现结论

m-ui v0.1 已按既定 Phase 0 至 Phase 8 顺序完成本地实现。项目以 SQLite
中的结构化状态为事实来源，通过类型化编译器生成确定性 Mihomo YAML，并使用
单一发布事务完成候选校验、原子发布、重载、健康检查和失败恢复。

本次实现没有加入 v0.1 范围外的 Docker、多节点、RBAC、公开订阅端点、任意
YAML 导入或编辑、其他协议和传输方式，以及用户级精确流量计费。

## 3. 架构与安全结果

- m-ui 和 Mihomo 的 systemd 服务均以独立非 root 用户运行。
- 面板默认仅监听 `127.0.0.1:2095`，Controller 仅监听回环地址并使用认证密钥。
- 所有浏览器写操作都要求已认证 Session 和 CSRF Header。
- 密码使用 Argon2id；Controller 密钥和 REALITY 私钥使用 Master Key 加密后存入
  SQLite。
- 所有业务配置使用类型化领域结构和 YAML 适配结构，不使用
  `map[string]any` 构建。
- 所有配置变更共用一个发布事务：同文件系统候选文件、固定参数
  `exec.CommandContext` 校验、文件和目录 fsync、原子替换、健康检查及回滚。
- 发布失败会同时恢复活动配置和结构化数据库状态；恢复失败进入 degraded 模式。
- 活动配置权限为 `0640`，Revision、备份、数据库和密钥保持私有权限。
- systemd 生命周期与日志命令使用固定绝对路径；sudoers 仅开放文档列出的
  Mihomo systemd 命令。
- 管理接口响应设置 CSP、禁止 framing、同源隔离、权限策略、no-referrer 和
  nosniff 等安全 Header；私有 JSON 响应禁止缓存。
- 日志和审计记录不包含密码、Controller 密钥、REALITY 私钥、完整 UUID、完整
  分享链接、Session/CSRF Token 或请求体。

## 6. 人工验收步骤

1. 在干净的 Debian 12+ 或 Ubuntu 24.04+ VM 上下载对应 Release 归档并执行：

   ```sh
   sudo ./scripts/install.sh --archive ./m-ui_<version>_linux_<arch>.tar.gz
   ```

2. 检查安装和服务：

   ```sh
   sudo /usr/local/bin/m-ui doctor --config /etc/m-ui/config.toml
   systemctl status m-ui.service mihomo.service
   ```

3. 从管理员工作站建立 SSH 隧道并访问 `http://127.0.0.1:2095`：

   ```sh
   ssh -L 2095:127.0.0.1:2095 <server>
   ```

4. 使用安装输出的初始管理员密码登录并立即修改密码。
5. 创建 VLESS/TCP/REALITY/XTLS Vision Listener，添加多个测试用户，导出分享链接，
   并在维护者自己的客户端和服务器上验证真实连接及流量。
6. 依次新增、禁用、删除测试用户，确认活动连接配置和 Revision 历史同步更新。
7. 在测试主机临时制造可恢复的 Mihomo 重载失败，确认活动配置和数据库状态恢复；
   不应使用生产实例进行破坏性测试。
8. 从历史 Revision 执行回滚，确认 UI、数据库状态和活动 YAML 一致。
9. 设置短期测试到期时间，确认用户到期后被批量禁用并只触发一次发布。
10. 重启服务器，确认两个服务自动恢复，Dashboard、数据库状态和活动配置一致。

## 7. 已知限制和未完成人工项目

- 仅管理本机单个 Mihomo 实例。
- 仅支持单管理员。
- 仅支持 VLESS over TCP、REALITY 和 XTLS Vision。
- 仅支持 systemd 部署的 Debian 12+ 和 Ubuntu 24.04+ 主机。
- 不支持 Docker、多节点、RBAC、公开订阅端点、其他协议/传输、任意 YAML
  导入或编辑。
- 流量、内存和连接数是实例级统计；不支持用户级精确流量计费、流量限额和
  IP 数限制。
- 尚未在本次 Windows 开发环境外创建干净 Linux VM 完成一次真实安装。
- 尚未代表维护者在其服务器上完成真实客户端外部流量验收。
- 尚未在完成安装的真实主机上执行整机重启一致性人工验收。
